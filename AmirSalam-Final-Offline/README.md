# امیر.سلام — نسخه لانچر

این نسخه به‌جای سرویس دسترسی‌پذیری، از یک **لانچر (صفحه اصلی جایگزین)** استفاده می‌کند.

## این نسخه چه کار می‌کند

- برنامه یک صفحه اصلی جایگزین است، شبیه لانچرهایی مثل «تبدیل به ویندوز».
- اسم برنامه‌ها در صفحه اصلی و کادر جست‌وجوی خودِ لانچر، طبق قانون‌هایی که در تب «تنظیمات» می‌سازید عوض می‌شود (مثلاً «برنامه‌ها» ← «سلاح‌ها»).
- تب «تنظیمات» شامل مدیریت قانون‌های اسم، تعداد ستون‌های صفحه اصلی، نمایش/عدم نمایش نوار جست‌وجو و دکمه‌ای برای باز کردن تنظیمات واقعی گوشی است. این صفحه، تنظیمات خودِ برنامه است، نه تنظیمات اصلی Android.
- بدون Root، بدون اینترنت، بدون سرویس دسترسی‌پذیری.

## محدودیت مهم

این روش فقط چیزهایی را عوض می‌کند که **خودِ لانچر رسم می‌کند**: صفحه اصلی و کادر جست‌وجوی لانچر.
متن داخل برنامه‌های دیگر (تنظیمات، پیام‌ها، مرورگر و غیره) را لانچر نمی‌بیند و نمی‌تواند عوض کند،
چون آن‌ها را خودِ همان برنامه رسم می‌کند.

## نصب و فعال‌سازی

1. APK را نصب کنید.
2. دکمه Home گوشی را بزنید؛ Android از شما می‌پرسد کدام لانچر پیش‌فرض باشد. «امیر.سلام» را انتخاب کنید.
3. برای تغییر بعدی، از تب «تنظیمات» دکمه «تغییر صفحه اصلی پیش‌فرض» یا از تنظیمات گوشی، بخش «برنامه پیش‌فرض ← صفحه اصلی» استفاده کنید.

## ساخت APK

برای ساخت از GitHub Actions کافی است فایل‌ها را در ریپو آپلود کنید؛
فایل `.github/workflows/build.yml` به‌طور خودکار APK را می‌سازد و در تب Actions، بخش Artifacts قابل دانلود است.

برای ساخت روی ویندوز بدون Android Studio، `BUILD_APK.bat` (یا برای نصب مستقیم `BUILD_AND_INSTALL.bat`) را اجرا کنید؛ این اسکریپت‌ها JDK 17 نصب‌شده و Gradle 8.9 (که خودش دانلود می‌شود) را لازم دارند.

## حریم خصوصی

- بدون حساب کاربری، بدون تبلیغات، بدون Analytics
- بدون ارسال داده به سرور
- بدون Root، بدون دستکاری APK برنامه‌های دیگر
- قانون‌های اسم و تنظیمات فقط به‌صورت محلی روی گوشی ذخیره می‌شوند
